# BIG CHRONICLE

**World of Warcraft: Forever**용 애드온입니다. 내가 걸어온 모험을 RPG 전기처럼 기록하고, 만난 몬스터를 종족별 도감에 모읍니다.

> 32레벨, 가시덤불 골짜기에서 첫 모험을 시작했다. 인간 전사 ○○의 전기가 이곳에서부터 기록된다.
> 34레벨, 낯선 땅 잊혀진 땅에 도착했다. 새로운 이야기가 기다리고 있을 것만 같다.
> 34레벨, 잊혀진 땅에서 처음으로 켄타우로스와 마주쳤다. 첫 기록은 「마그람 약탈자」. (도감 No.008)
> 「마라우돈」 원정을 마쳤다. — 소요 시간 1시간 12분, 쓰러뜨린 보스 4명, 쓰러짐 1회

---

## 설치

1. `BigChronicle` 폴더를 통째로 WoW Forever 설치 폴더의 `Interface\AddOns\` 안에 복사합니다.
   (`Interface\AddOns\BigChronicle\BigChronicle.toc` 경로가 되어야 합니다.)
2. 게임을 켜고 캐릭터 선택 화면의 **애드온** 목록에서 BIG CHRONICLE을 켭니다.
3. 접속하면 첫 기록이 자동으로 남습니다. `/bc` 로 창을 엽니다.

### 인터페이스 버전

TOC에는 Forever 인터페이스 번호 `16001`이 들어 있습니다. 출시 뒤 패치로 번호가 바뀌어 애드온 목록에 "구 버전"으로 표시되면, 게임에서 아래 명령으로 현재 번호를 확인해 `BigChronicle.toc`의 `## Interface:` 줄을 고치거나, 애드온 목록에서 **구 버전 애드온 불러오기**를 켜 주세요.

```
/dump select(4, GetBuildInfo())
```

## 기능

### 📖 모험 일지 (RPG 전기)

자동으로 기록되는 것:

| 분류 | 기록 내용 |
|---|---|
| 탐험 | 처음 방문한 지역, 처음 찾은 세부 장소 |
| 성장 | 레벨업 (10·20·…·60 레벨은 특별한 문장, 지난 레벨 이후 접속해 있던 시간), 처음 모은 골드(1·50·250·500 — 나머지는 업적으로), 귀환석 위치 변경 |
| 퀘스트 | 완료한 퀘스트 (경험치·골드 보상 표시) |
| 던전·전장 | 던전/공격대 원정 시작, 보스 처치(첫 처치·통산 횟수), 원정 종료 요약(소요 시간·보스 수·쓰러짐·전멸), 전장 참전 |
| 도감 | 새 종족과의 첫 만남(종족마다 다른 소설 같은 장면 묘사, 시간대 반영), 희귀 개체 발견/처치, 종족 처치 칭호(50·100·250·500·1000), 연구 등급 상승 |
| 업적 | 업적을 이룰 때마다 한 줄의 이야기 |
| 시련 | 죽음 (마지막으로 맞서던 상대) |
| 나의 기록 | 직접 남기는 메모 — `/일지 오늘 처음으로 그리핀을 탔다` |

- 레벨대에 따라 **7개의 장(章)** 으로 나뉩니다: 제1장 · 첫걸음(1~9) → … → 제7장 · 아제로스의 영웅(60)
- 날짜별로 묶어서 보여 주고, 분류별 필터와 정렬(오래된순/최신순)을 지원합니다.
- **내보내기**로 전기 전체를 복사 가능한 글로 뽑을 수 있습니다.
- 던전 안에서 죽어 영혼으로 달려 나왔다가 15분 안에 돌아오면 같은 원정으로 이어집니다.
- 한국어 조사를 자동으로 맞춥니다 (가시덤불 골짜기**를** / 잊혀진 땅**을** / 무법항**으로**).

### 🐾 몬스터 도감 (포켓몬 도감처럼)

몬스터를 **대상으로 지정하거나, 마우스를 올리거나, 이름표가 보이면** 처음 본 순간 도감에 등록됩니다.

- **34개 종족** (No.001 멀록, 놀, 코볼트, 트로그, 오우거, 트롤, 하피, 켄타우로스, 가시멧돼지, 펄볼그, 사티로스, 나가, 예티와 웬디고, 늑대인간, 데피아즈 형제단, 신디케이트, 붉은십자군, 투자개발회사, 해적, 검은무쇠 드워프, 적대 오크 부족, 황혼의 망치, 성난토템 부족, 실리시드, 용족, 악마, 정령, 거인, 언데드, 기계, 야수, 작은 동물, 기타 인간형, 미지의 존재)
- 늑대·거미·랩터 같은 **야수 계통**은 만날 때마다 No.035부터 새 항목이 생깁니다.
- 아직 못 만난 종족은 `???` 와 힌트 한 줄만 보입니다.
- 종족마다 **배경 이야기 3단락**이 있고, 연구 등급이 오를 때마다 하나씩 해금됩니다.
  - 연구도 = 발견한 종 ×10 + 처치 + 희귀 개체 ×50 + 우두머리 ×20
  - ★ 조우 → ★★ 관찰자(60) → ★★★ 연구자(200) → ★★★★ 권위자(600) → ★★★★★ 전설의 사냥꾼(1500)
- **서식지**: 실제로 만난 지역과 횟수, 그리고 알려진 서식지 힌트
- **희귀 개체 모음**: 희귀/희귀 정예를 따로 모아 보고, 처치했는지 표시
- 개체를 고르면 오른쪽 카드에 **3D 모습**(드래그로 회전), 레벨 범위, 등급, 처치·목격 수, 첫 발견 정보가 나옵니다.
- 몬스터 툴팁에 `[도감] No.001 멀록 · 처치 23` 이 붙습니다.

#### 종족 분류 방식

1. 사용자가 직접 지정한 분류 (개체 오른쪽 클릭 → 종족 다시 분류)
2. 이름 키워드 (한국어·영어): 멀록, 코볼트, 오우거, 데피아즈, 붉은십자군 …
3. **이름 접두어 학습**: "강바닥발톱 놀"을 놀로 분류하면, 이후 "강바닥발톱 잡종개"도 놀로 분류합니다. 이미 '기타 인간형'에 들어가 있던 개체도 자동으로 옮겨집니다.
4. 생물 유형 (용족, 악마, 정령, 언데드, 야수 계통 …)

자동 분류가 틀렸다면 도감에서 개체를 **오른쪽 클릭**해 직접 고칠 수 있습니다.

### 🏆 업적 (386개)

리치 왕 시절의 클래식(1~60) 콘텐츠 업적을 참고해, **Forever 공식 업적과 겹치지 않는 부분**과 이 애드온만의 업적을 모았습니다. (비교표: [docs/achievements.md](docs/achievements.md))

- **성장**: 10~60레벨, 10~5,000골드, 모험 시간
- **탐험**: 방문한 지역·장소 개수, 귀환석 (지역별 탐험은 Forever 공식 업적에 있음)
- **퀘스트**: 10~1,000개, 여러 지역/한 지역의 퀘스트
- **던전·공격대**: 클래식 던전 19곳·공격대 7곳 각각의 정복, 정복 개수, 원정 횟수, 보스 처치, 전멸 후 재도전, 무사 귀환
- **몬스터 도감**: 종족·개체·희귀 개체·처치 수·연구 등급·야수 계통·종족별 100마리
- **종족 연구**: 34개 종족마다 첫 만남 · ★★★ 연구자 · 100마리 처치
- **이야기꾼**: 클래식 지역 40곳 각각의 퀘스트, 동부 왕국·칼림도어·아제로스의 이야기꾼
- **전장·평판·시련·연대기**: 참전, 확고한 동맹 수, 첫 죽음과 무사 레벨업, 나만의 기록·내보내기
- **소소한 재미**: 현실의 날짜로 판정하는 업적 — 7일·30일 연속 기록, 백일의 동행, 주말 전사, 올빼미 모험가, 새해 첫 모험 등
- 업적을 이루면 양피지 알림에 밀랍 인장이 찍히고, 짧은 이야기 한 줄이 전기에 남습니다.

### ✨ 연출

- 창을 열면 가죽 표지 위에 **BIG CHRONICLE 로고**가 잠깐 보였다가 스르르 사라집니다
- 새 장(章)에 들어서면 화면 가운데에 **양피지 두루마리가 좌우로 펼쳐지고 장 제목**이 떠오르며, 금가루가 흩날립니다 (전기가 처음 시작될 때도)
- 알림이 내려앉으면 **붉은 밀랍 인장이 찍힙니다** — 업적은 리본 달린 나침반 별 인장, 도감 발견(새 종족·새 개체·희귀 개체·연구 등급)은 사자 문장 인장
- 새로 발견한 종족 페이지를 처음 펼치면 **밀랍 인장**이 찍히고, 목록에는 아직 안 본 종족에 NEW 표시가 붙습니다
- 새로 이룬 업적은 처음 볼 때 3초 동안 금빛으로 빛난 뒤 멈추고, 탭을 떠날 때까지 NEW 표시와 옅은 금빛만 남습니다
- 창을 닫아 둔 사이에 새 소식이 생기면 **미니맵 버튼이 반짝입니다**
- 설정에서 '화면 연출'을 끄면 모두 꺼집니다

### 🎨 화면 구성

**금장식 가죽 도감 수첩** 모양입니다. 창틀, 명판, 탭, 버튼, 양피지, 두루마리, 밀랍 인장, 아이콘까지 모두 제작자가 직접 준비한 에셋 시트(`art/`)에서 잘라 쓴 그림입니다.

- 금테를 두른 **가죽 창틀**, 위쪽 명판에 **금빛 BIG CHRONICLE 글자**, 왼쪽 위에 **업적 깃발**
- 사다리꼴 **가죽 탭**(선택한 탭은 금빛)에 메달 아이콘, 탭 이름은 게임 기본 글꼴 중 **제목 강조 글꼴**
- **모험 일지**: 왼쪽은 가죽 위의 장 목록(기록 수 배지)과 분류 체크박스, 오른쪽은 양피지 위의 날짜별 **타임라인**
- **몬스터 도감**: 목록 · 상세 · 모습의 세 단, 3D 모습은 금테 액자에
- **업적**은 메달 아이콘과 진행 막대, **통계**는 양피지 한 장에 정리
- 글자색은 가죽 위에서는 밝은 양피지색, 양피지 위에서는 진한 잉크색, 글꼴은 **게임 기본 글꼴**
- 배경 이야기가 **한 글자씩 써지는** 연출 (클릭이나 Space로 바로 보기)
- 새 기록이 들어오면 일지에 **천천히 떠오르듯** 나타납니다
- **키보드 단축키**: `1~5` 탭 전환, `←/→` 일지 쪽 넘기기, `↑/↓` 도감 종족 넘기기, `Space` 글 바로 보기, `Esc` 닫기
  (전투 중에는 자동으로 꺼집니다)
- 도감 알림은 화면 위쪽에 **양피지 전갈**처럼 내려앉고 붉은 밀랍 인장이 찍힙니다. **알림을 누르면 그 몬스터의 도감 페이지**(종족·개체·3D 모습)가 바로 열리고, 업적 알림은 그 업적으로 이동합니다

## 명령어

| 명령어 | 설명 |
|---|---|
| `/bc`, `/연대기` | 창 열기/닫기 |
| `/bc 일지` · `/bc 도감` · `/bc 업적` · `/bc 통계` · `/bc 설정` | 해당 탭 열기 |
| `/일지 <내용>`, `/bc 기록 <내용>` | 나만의 기록 남기기 |
| `/도감` | 몬스터 도감 열기 |

| `/bc 미니맵` | 미니맵 버튼 보이기/숨기기 |

미니맵 버튼(금테 B.C 메달): 왼쪽 클릭 = 일지, 오른쪽 클릭 = 도감, 드래그 = 위치 이동

## 알아 두면 좋은 점

- 기록은 **캐릭터마다** 따로 저장됩니다 (`BigChronicleCharDB`). 설정은 계정 공통입니다 (`BigChronicleDB`).
- 애드온을 설치하기 **전**의 모험은 알 수 없으므로, 설치한 순간부터 기록이 시작됩니다.
  그래서 32레벨 캐릭터라면 첫 기록이 "32레벨, ○○에서 첫 모험을 시작했다."가 됩니다.
- 처치 수는 '대상/이름표의 죽음 감지'와 '경험치 획득 메시지' 두 가지로 세고, 겹치는 것은 상쇄합니다.
  경험치를 주지 않는 몬스터를 대상 지정 없이 잡으면 빠질 수 있습니다.
- 진영 NPC(경비병 등), 우호적인 NPC, 토템, 애완동물은 도감에 넣지 않습니다.
- **비행 조련사의 와이번·그리핀을 타고 날아가는 동안에는** 지나가는 지역·세부 장소와 내려다본 몬스터를 발견으로 치지 않습니다 (탐험 기록·도감·발견 업적 모두). 직접 찾아가야 진짜 발견입니다. 내린 곳은 내린 뒤에 기록됩니다.
- 3D 모습은 게임이 해당 몬스터 정보를 기억하고 있을 때만 나타납니다.

```
└─ UI/                 Atlas(그림 조각 정보), 위젯, 메인 창, 일지/도감/업적/통계/설정 탭, 연출, 알림, 미니맵
curseforge/            CurseForge 설명글, 변경 내역, 프로젝트 아이콘(PNG)
art/                   화면 그림 원본 (에셋 시트 3장, 로고 logo.png, 명판 글자 title.png, 미니맵 아이콘 minimap.png)
tools/                 slice_assets.py: 에셋 시트를 잘라 Media/UI/*.tga 와 UI/Atlas.lua 생성, build_assets.py: 효과 입자·효과음
tests/
├─ mockwow.lua         일반 Lua 5.1에서 돌아가는 최소한의 WoW API 흉내
├─ test_run.lua        로그인 → 탐험 → 레벨업 → 퀘스트 → 도감 → 던전 → UI 조작 시나리오 테스트
└─ sim_journey.lua     1~60레벨 장기 여정 시뮬레이션 (접속 종료·던전 재입장·업적까지 검사하고 전기 전문 출력)
```

게임 없이 로직을 검사하려면 (Lua 5.1 필요):

```
lua5.1 tests/test_run.lua
lua5.1 tests/sim_journey.lua 7
```

에셋 시트(`art/`)를 고친 뒤 그림 조각을 다시 만들려면 (Python + Pillow, numpy, scipy 필요):

```
python3 tools/slice_assets.py
```

아이콘을 다시 만들려면 (Python + Pillow, Node Playwright 필요):

```
NODE_PATH=$(npm root -g) python3 tools/make_icon.py out/
```
