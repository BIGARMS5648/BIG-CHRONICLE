BIG CHRONICLE - assets
======================

1) Interface art (UI\*.tga)
   Window frame, plaque, tabs, buttons, parchment panels, scroll, wax
   seals, medallion icons, scrollbar, check boxes, bars and buckles.
   Source  : asset sheets provided by the addon author (art\ in the
             source repository), cut into pieces by tools/slice_assets.py
   License : part of BIG CHRONICLE; not for reuse outside this addon
             without the author's permission.

2) Effect particles: Kenney "Particle Pack"
   Files   : FX\Star.tga, FX\Glow.tga, FX\Crumb.tga, FX\Magic.tga
             (star_06, light_01, dirt_02, magic_05; resized to 64x64)
   Source  : https://kenney.nl/assets/particle-pack
   License : CC0 1.0 (public domain)

3) Sound effects: Kenney "RPG Audio"
   Files   : Sounds\bookOpen.ogg, bookClose.ogg, bookFlip1-3.ogg, bookPlace1.ogg
   Source  : https://kenney.nl/assets/rpg-audio
   License : CC0 1.0 (public domain)

Fonts: none bundled. The addon uses the game's own fonts.
