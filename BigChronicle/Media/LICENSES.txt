BIG CHRONICLE - third-party assets
==================================

The textures in this folder were generated by tools/build_assets.py from the
free assets below. The originals were resized, recolored, combined with
procedurally drawn details (paper fibers, ink, tape, stitching) and saved as TGA.


1) Paper and leather texture: Subtle Patterns
   Files used : exclusive_paper.png, leather_1.png
   Used in    : Paper.tga, Leather.tga (and every texture tinted from them)
   Source     : https://github.com/atlemo/SubtlePatterns
   License    : Creative Commons Attribution-ShareAlike 3.0 (CC BY-SA 3.0)
                https://creativecommons.org/licenses/by-sa/3.0/
   Credit     : Subtle Patterns (subtlepatterns.com), Toptal
   Changes    : resized, made seamless, converted to grayscale for tinting.
                Paper.tga and Leather.tga are shared under the same license.


2) Icons and wax seal design: game-icons.net
   Icons used : wax-seal, flat-paw-print, laurels-trophy, scroll-quill,
                paw-print, histogram, cog, magnifying-glass, quill-ink,
                footprint, star-medal, compass, sparkles
   Used in    : Seal.tga, SealDex.tga, SealAch.tga, Icons\*.tga
   Source     : https://game-icons.net  (via the @iconify-json/game-icons package,
                https://github.com/game-icons/icons)
   License    : Creative Commons Attribution 3.0 (CC BY 3.0)
                https://creativecommons.org/licenses/by/3.0/
   Credit     : Icons by Lorc, Delapouite and the game-icons.net contributors
   Changes    : rasterized; the wax seals were shaded, embossed and colored
                as red wax with an emblem pressed in the middle.


3) Handwriting font: Nanum Pen Script
   File       : Fonts\NanumPenScript.ttf
   Source     : https://github.com/google/fonts/tree/main/ofl/nanumpenscript
   License    : SIL Open Font License 1.1 (full text: Fonts\NanumPenScript-OFL.txt)
   Credit     : Copyright (c) 2010, NHN Corporation (now NAVER), Reserved Font Name "Nanum"


Everything else in this folder (Grid, Hole, Ring, Tape, Sticky, Torn,
Underline, Check, PenCircle, Ink, Paperclip, Stitch, Ribbon, Icon) was drawn
from scratch by tools/build_assets.py and is part of BIG CHRONICLE.
