BIG CHRONICLE - third-party assets
==================================

The textures in this folder were generated by tools/build_assets.py from the
free assets below. The originals were resized, recolored, combined with
procedurally drawn details (stains, burnt edges, brass, gold tooling) and
saved as TGA.


1) Parchment and leather textures: Subtle Patterns
   Files used : natural_paper.png, leather_1.png
   Used in    : Parchment.tga, Leather.tga
   Source     : https://github.com/atlemo/SubtlePatterns
   License    : Creative Commons Attribution-ShareAlike 3.0 (CC BY-SA 3.0)
                https://creativecommons.org/licenses/by-sa/3.0/
   Credit     : Subtle Patterns (subtlepatterns.com), Toptal
   Changes    : resized, made seamless, converted to grayscale for tinting,
                aged with generated stains and wear. Parchment.tga and
                Leather.tga are shared under the same license.


2) Crest, icons and wax seal design: game-icons.net
   Icons used : wax-seal, griffin-symbol, dragon-head, laurel-crown,
                fleur-de-lys, quill-ink, hourglass, cog
   Used in    : Seal.tga, SealDex.tga, SealAch.tga, Emblem.tga, Fleuron.tga,
                Icons\*.tga
   Source     : https://game-icons.net  (via the @iconify-json/game-icons package,
                https://github.com/game-icons/icons)
   License    : Creative Commons Attribution 3.0 (CC BY 3.0)
                https://creativecommons.org/licenses/by/3.0/
   Credit     : Icons by Lorc, Delapouite and the game-icons.net contributors
   Changes    : rasterized; the wax seals were shaded, embossed and colored
                as red wax with an emblem pressed in the middle.


3) Title font: Nanum Myeongjo ExtraBold
   File       : Fonts\NanumMyeongjo-ExtraBold.ttf
   Source     : https://github.com/google/fonts/tree/main/ofl/nanummyeongjo
   License    : SIL Open Font License 1.1 (full text: Fonts\NanumMyeongjo-OFL.txt)
   Credit     : Copyright (c) 2010, NHN Corporation (now NAVER), Reserved Font Name "Nanum"


Everything else in this folder (Vignette, Corner, SpineBand, OrnCorner, Dust,
Check, Ink, Ribbon, Icon) was drawn from scratch by tools/build_assets.py and
is part of BIG CHRONICLE.
